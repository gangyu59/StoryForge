# StoryForge

StoryForge 是一个基于 LLM 的互动故事引擎。

## 快速开始

1.  克隆仓库：
    ```bash
    git clone https://github.com/your-username/StoryForge.git
    ```
2.  配置 API Key：
    *   复制 `js/core/llm_config.example.js` 为 `js/core/llm_config.js`。
    *   在 `js/core/llm_config.js` 中填入你的 API Key。
3.  运行：
    *   直接在浏览器中打开 `index.html`，或者使用本地服务器（如 VS Code 的 Live Server）运行。
