# For You Missions Feed：信息流规格

## 1. 信息流入口（替代“单剧情入口”）
玩家打开游戏，进入“为你推荐”任务流（Feed），包含 3–6 张卡片。
每张卡片都是一个可开始/可继续的任务（Mission Card）。

Feed 是“推荐式游戏”的核心界面，而不是剧情段落。

## 2. 卡片类型（最小集合）
必须至少支持以下 5 类卡片：

### A) Continue Mainline（继续主线）
- 目的：承接上次未完故事与悬念
- 显示：上次关键点 + 下一步的紧迫理由
- 触发：存在 active_mainline（未完成）

### B) You’ll Like This（偏好支线）
- 目的：像头条一样喂你“对味”的内容
- 显示：题材/情绪/节奏贴合画像
- 触发：从画像中挑选 top 1–2 偏好

### C) You Can Win（可赢挑战）
- 目的：立刻给成就感，避免无力感与无聊
- 显示：明确目标 + 明确奖励 + 风险可控
- 触发：玩家最近失败或停留过久；或需要强反馈

### D) Someone Needs You（被需要求助）
- 目的：建立责任感与情感回流
- 显示：某 NPC 的求助/依赖/请求兑现承诺
- 触发：存在 bond_anchor 角色；或有 vow 未兑现

### E) High Stakes（高风险高回报窗口期）
- 目的：制造“错过就没有”的回流钩子
- 显示：倒计时 + 回报 + 后果
- 触发：玩家能力达到阈值；或剧情到关键阶段

## 3. 卡片字段（UI/存储需要）
每张卡片至少包含：
- id
- type（A/B/C/D/E）
- title（短）
- hook（两行以内强钩子）
- why_you（为什么推荐给你：一句话）
- reward（奖励：解锁/称号/关键道具/关系提升）
- risk（风险：名声/关系/窗口期/暴露）
- urgency（none / soon / deadline）
- start_action（点击后进入哪个任务节点）

## 4. 排序逻辑（推荐与供给）
排序优先级建议：
1) Inbox 中有 deadline 的窗口期卡片（E）
2) Continue Mainline（A）
3) Someone Needs You（D）
4) You Can Win（C）
5) You’ll Like This（B）

但必须加入多样性约束：
- 同类型卡片最多连续 2 张
- 同题材/同情绪最多 2 张

## 5. “为什么推荐给你”（必须展示）
每张卡片必须显示 why_you：
- 例如：“你更偏好动脑解谜，且你最近选择了冷静策略”
- 例如：“你总在救人时坚持承诺，这次有人在等你兑现”

这个字段让玩家产生“被理解”的即时感。

## 6. Anti-boring Gate（防无聊规则）
如果某任务连续 2 回合没有：
- 新信息（truth）
- 新关系变化（bond）
- 新能力/解锁（agency）
则系统必须：
- 强制插入新变量（新角色/倒计时/不可逆后果）
- 或推荐一条 You Can Win 的任务替代
