# PLAYER_PROFILE_AND_RETURN_LOOP.md

# 玩家画像 + 回流机制：可解释的推荐式游戏循环

## 1. 玩家画像（最小可用 6 维）
画像不是问卷，是从行为推断、持续校准。

### 维度定义（每维 0–3 档）
1) Theme（题材）：救援 / 谍战 / 解谜 / 超能 / 治愈
2) Mood（情绪）：爽感 / 紧张 / 温暖 / 成长 / 反转
3) Pace（节奏）：快推进 / 慢沉浸
4) Challenge（挑战）：动脑 / 执行 / 社交 / 资源调度
5) Role（角色自我）：英雄 / 守护者 / 策士 / 执行者
6) Avoid（厌恶项）：重复探索、无进展、无意义对话等（布尔或权重）

## 2. 推断规则（示例）
- 选择“救人/保护/承担风险” → Role: 守护者/英雄 +1；Theme: 救援 +1
- 选择“推理/拆解/规划” → Challenge: 动脑 +1；Theme: 解谜 +1
- 选择“冒险/潜入/追踪” → Mood: 紧张 +1；Pace: 快推进 +1
- 连续两次点“继续观察/继续探索”且无新信息 → Avoid: 无进展 +2（强惩罚）

## 3. 供给循环（Feed Loop）
每回合都同时完成两件事：
- 推进一个任务（故事/任务向前）
- 更新画像（训练推荐）

因此玩家会感到：
“我越玩越像我自己”，系统越懂我。

## 4. 回流机制（World Inbox）
世界留言箱的目的：
- 让玩家离开后回来有“未读/未结/窗口期”的强理由
- 让玩家感到“被需要/被追责/被期待”

Inbox 消息类型（最小 3 类）：
A) Window（窗口期事件）：倒计时，错过会改变结局
B) Bond（关系消息）：某 NPC 求助/依赖/道谢/质问
C) Consequence（后果追责）：你上次的决定造成后果，需要补救

Inbox 生成规则（最低限度）：
- 玩家每完成 1 个里程碑，生成 1 条 Bond 或 Consequence
- 玩家离开超过 N 分钟，生成 1 条 Window（可选）
- 连续无进展时，生成 1 条 Consequence（逼迫变化）

## 5. 成长机制（Agency Unlocks：选择权升级）
禁止“纯数值升级”作为主要成长。
必须让玩家感到“我现在能做以前不能做的事”。

解锁示例：
- 解锁“追问一次”：本回合可额外向 NPC 追问一个关键问题
- 解锁“改写一次”：允许撤回一次选择，代价是名声/关系下降
- 解锁“并行一次”：一次行动推进两条线索（但风险上升）
- 解锁“看穿谎言”：对话中可揭穿一次矛盾（影响关系）

解锁触发：
- 达到某身份里程碑（称号）
- 完成某关键救援/破局任务
- 与关键 NPC 建立信任/依赖

## 6. 里程碑奖励（叙事认可 + 结构化记录）
每个里程碑必须同时产出：
- 称号（Identity）
- 关系变化（Bond）
- 世界评价（World）
- 解锁（Agency）
并写入可检索的记忆（mid/long term）。

这样玩家会感到：
“我不是在点选项，我在成为某个人。”
