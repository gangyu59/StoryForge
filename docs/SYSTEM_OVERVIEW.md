# StoryForge — System Overview

## 1. What is StoryForge

StoryForge is an AI-native narrative game system designed to create
choice-driven interactive stories where meaning emerges from
consequences, relationships, and identity — not from levels or stats.

The system is not a content generator.
It is a **decision engine with narrative expression**.

AI assists narration.
The system determines truth.

---

## 2. Core Design Goals

- Build a playable narrative system, not a tech demo
- Preserve player agency through deterministic rules
- Allow meaningful endings without forcing a single outcome
- Enable long-term extensibility without refactoring

---

## 3. What StoryForge Is Not

- Not a sandbox with infinite randomness
- Not a stat-based RPG
- Not an AI-controlled world simulator
- Not an auto-writing story generator

---

## 4. Core Philosophy

1. System-driven, AI-assisted  
   - Rules, state, milestones are deterministic
   - AI only expresses meaning and atmosphere

2. Memory belongs to the system  
   - World and NPC memory are structured and persistent
   - AI receives summaries, never raw authority

3. Milestones over levels  
   - Progress is defined by irreversible state shifts
   - Recognition replaces grinding

4. Playable closure  
   - Each chapter can end
   - Endings are conclusions, not failures

---

## 5. Player Experience Promise

Players will feel that:
- The world responds consistently to their choices
- NPCs remember what matters
- Progress is acknowledged and recorded
- Stopping feels meaningful, not empty

StoryForge is about **becoming**, not winning.
